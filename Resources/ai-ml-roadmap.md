# AI/ML Engineer Roadmap

A phase-based path — no dates, just order. Move to the next phase when the current one feels solid, not when you've memorized everything in it.

---

## Phase 0 — Foundations (in progress)
- [ ] Python for Data Analysis (finishing)
- [ ] Mathematics for Machine Learning (PDF — mml-book.github.io)
- [ ] 3Blue1Brown: Essence of Linear Algebra
- [ ] 3Blue1Brown: Neural Networks

> Math runs *alongside* the coding, not before it. Don't gate yourself waiting to "finish" the math book.

---

## Phase 1 — Classical ML
- [ ] Hands-On Machine Learning (Géron) — chapters 1–9 (classical ML: regression, trees, ensembles, SVMs, clustering)
- [ ] Kaggle account — start "Getting Started" competitions (Titanic, House Prices) once you're a few chapters in

---

## Phase 2 — Deep Learning
- [ ] Hands-On Machine Learning (Géron) — chapters 10–19 (neural nets, CNNs, RNNs, autoencoders, deployment basics)
- [ ] Machine Learning with PyTorch and Scikit-Learn (Raschka)

---

## Phase 3 — LLMs from the Ground Up
- [ ] LLMs-from-scratch repo — main chapters (ch01–ch07)
- [ ] LLMs-from-scratch repo — bonus material (KV cache, GQA, MLA, MoE, DPO, etc.)

---

## Phase 4 — LLM Ecosystem & Practical Skills
- [ ] Hugging Face NLP Course (huggingface.co/learn/nlp-course)
- [ ] Hugging Face PEFT docs — LoRA/QLoRA fine-tuning
- [ ] FastAPI docs — serve a trained model as an API
- [ ] DeepLearning.AI short courses — LangChain + a RAG-focused course

---

## Phase 5 — Production / MLOps
- [ ] Docker — install Docker Desktop, work through "Get Started" docs
- [ ] Weights & Biases *or* MLflow — experiment tracking
- [ ] DVC — data/model versioning
- [ ] AWS SageMaker docs — deploy something end-to-end

---

## Phase 6 — Portfolio
- [ ] 2–3 end-to-end projects: data → train → serve (FastAPI) → track (W&B/MLflow) → deploy (Docker/SageMaker)
- [ ] Push all of it to GitHub with clear READMEs

---

### Rule of thumb for moving phases
You don't need mastery to advance — you need to be able to *use* what the phase taught you without constantly looking things up. If you're still confused on the fundamentals of a phase, stay. If you're just slow but understand it, move on and let practice sharpen you.
